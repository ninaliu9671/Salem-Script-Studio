# Salem Script Studio · 《塞勒姆女巫》排练助手

本工具专为剧组排练《塞勒姆女巫》设计，基于 GitHub Pages 部署，无需安装任何软件。  
它从仓库中的 `script.md` 文件自动读取剧本，支持多幕切换、角色台词隐藏/提示、声线选择、快速跳转等排练功能。

## 主要功能

- 📖 **多幕剧本**：自动识别 `### 第一幕 ###` 等标题，支持多幕切换。
- 🎭 **角色台词隐藏**：选定角色后，你的台词会整行高亮并隐藏原文，模拟盲背。
- 💡 **渐进提示**：点击「提示/我说完了」→ 第一次显示原文（永久显示），第二次确认进入下一句。
- 🔊 **角色声线**：可为每个角色选择不同的语音（Edge 浏览器内置自然语音或本地语音）。
- 🔍 **快速跳转**：一键跳转到自己的上一句/下一句台词，无需手动翻找。
- 🔎 **台词搜索**：搜索角色名或台词内容，关键词高亮，定位迅速。
- 🧹 **自动清理**：舞台指示（括号内容）自动删除，不会被朗读。

## 使用指南

### 对于普通成员（演员）

1. 打开仓库的 GitHub Pages 网址（由管理员提供）。
2. 左侧「角色表」中可以为每个角色试听并选择声线（🎧）。
3. 右侧「我的角色」下拉菜单中选定你要扮演的角色 → 你的所有台词会变成黄色高亮并隐藏原文。
4. 点击「▶ 开始排练」：
   - 其他角色台词由系统自动朗读。
   - 轮到你的台词时，页面显示 `???`，点击「💡提示/我说完了」按钮：
     - **第一次点击**：显示当前台词原文（之后永久显示）。
     - **第二次点击**：确认说完，自动进入下一句。
5. 排练过程中，可使用「⬆️上一句/⬇️下一句我的台词」快速跳转到自己的台词段落。
6. 需要查找特定台词或角色时，使用搜索框（按回车执行）。

### 对于导演/编剧（修改剧本）

1. 确保你有该 GitHub 仓库的**写入权限**（仓库 Settings → Collaborators 中添加）。
2. 直接在 GitHub 网页上编辑 `script.md` 文件：
   - 打开仓库 → 点击 `script.md` → 点击铅笔图标 ✏️。
   - 按以下格式修改或增删台词：

     ### 第一幕 ###
     角色名：台词内容
     角色名：台词内容

     ### 第二幕 ###
     ...

   - 舞台指示（如 `（罗密欧上场）`）会被自动忽略，无需删除。
   - 修改后滚动到页面底部，点击 **Commit changes** 保存。
3. 等待约 1 分钟，GitHub Pages 会自动重新部署。成员刷新页面即可看到最新剧本。

## 文件结构

- index.html  // 排练工具主页面
- script.md   // 剧本文件（Markdown 格式，按幕拆分）
- README.md   // 本说明文件

## 技术说明

- 纯前端实现（HTML/CSS/JS），无后端依赖。
- 剧本通过 `fetch('script.md')` 动态加载，修改后实时生效。
- 个人排练进度（已提示的台词、当前行、角色选择等）保存在浏览器的 `localStorage` 中，不同设备独立。
- 语音合成依赖 Web Speech API，推荐使用 **Microsoft Edge** 浏览器以获得最自然的在线语音。

## 常见问题

**问：为什么有些语音无法发声？**  
答：请点击「一键检测可用语音」按钮，工具会自动筛选出真正能用的语音。推荐使用 Edge 浏览器。

**问：修改 `script.md` 后，页面没有变化？**  
答：GitHub Pages 刷新需要几十秒到一分钟，请稍后强制刷新页面（Ctrl+F5）。

**问：我可以自己在本地测试吗？**  
答：可以。将 `index.html` 和 `script.md` 放在同一个文件夹，用浏览器打开 `index.html` 即可（注意某些浏览器可能因安全策略限制 `fetch` 本地文件，建议通过 `npx serve` 或 VS Code Live Server 运行）。

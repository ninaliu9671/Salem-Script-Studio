# Salem Script Studio · 《萨勒姆的女巫》台词练习助手

本工具专为剧组排练《萨勒姆的女巫》设计，基于 GitHub Pages 部署，无需安装任何软件。  
它从仓库中的 `script.md` 文件自动读取剧本，通过 `audio/` 目录中的预录音频实现角色朗读，支持多幕切换、台词隐藏提示、快速跳转等排练功能。

## 主要功能

- 📖 **多幕剧本**：自动识别 `### 第一幕 ###` 等标题，支持多幕切换。
- 🎭 **角色台词隐藏**：选定角色后，你的台词会整行高亮并默认隐藏原文，模拟盲背。
- 💡 **一键全显示/全隐藏**：选定角色后，点击「💡 全显示我的台词」一键显示所有台词（适合先浏览）；点击「🙈 全隐藏我的台词」一键重新遮住（适合开始练习或重练）。
- 🔘 **单行可切换提示**：点击台词右侧「💡 提示」显示原文；再次点击「🙈 隐藏」可重新遮住，随时反复练习。
- 🔊 **预录音频朗读**：其他角色的台词通过预先录制的 WAV 文件自动播放，音色真实自然。
- 🤖 **全自动模式**：不选择角色时，所有台词均自动连续播放，可用于听整幕剧。
- 🔍 **快速跳转**：一键跳转到自己的上一句/下一句台词，无需手动翻找。
- 🔎 **台词搜索**：搜索角色名或台词内容，关键词高亮，定位迅速。
- 📍 **进度保存**：排练进度（当前句、当前幕、角色选择）自动保存，下次打开自动恢复。
- 🎬 **舞台提示切换**：可一键隐藏或显示剧本中的舞台指示文字。

## 使用指南

### 对于普通成员（演员）

1. 打开仓库的 GitHub Pages 网址（由管理员提供）。
2. 在「我的角色」下拉菜单中选定你要扮演的角色 → 你的所有台词会变成黄色高亮并隐藏原文。
3. 按需使用「💡 全显示我的台词」先浏览一遍，熟悉后点「🙈 全隐藏我的台词」准备练习。
4. 点击「▶ 开始排练」：
   - 其他角色台词由系统自动播放预录音频。
   - 轮到你的台词时，系统暂停并提示「🎭 轮到你了！」。
   - 点击台词右侧的「💡 提示」按钮查看单句原文（可再次点击「🙈 隐藏」重新遮住）。
   - 台词说完后，点击控制栏中的「✅ 我说完了」，系统自动继续播放下一句。
5. 排练一遍后若台词已全部显示，点「🙈 全隐藏我的台词」重置遮盖，即可再练一遍。
6. 排练过程中，可使用「⬆️上一句/⬇️下一句我的台词」快速跳转到自己的台词段落。
7. 需要查找特定台词或角色时，使用搜索框（按回车执行）。
8. 点击任意台词行可直接跳转到该位置开始排练。
9. 下次打开页面会自动恢复上次的排练进度。

### 对于导演/编剧（修改剧本）

1. 确保你有该 GitHub 仓库的**写入权限**（仓库 Settings → Collaborators 中添加）。
2. 直接在 GitHub 网页上编辑 `script.md` 文件：
   - 打开仓库 → 点击 `script.md` → 点击铅笔图标 ✏️。
   - 按以下格式修改或增删台词：

     ### 第一幕 ###
     角色名：台词内容
     角色名：台词内容

     ### 第二幕 ###
     ...

   - 舞台指示（如 `〔罗密欧上场〕`）保留在剧本中，工具会以斜体灰色显示，不会被朗读。
   - 修改后滚动到页面底部，点击 **Commit changes** 保存。
3. 等待约 1 分钟，GitHub Pages 会自动重新部署。成员刷新页面即可看到最新剧本。

> **注意**：修改剧本后，旧台词对应的预录音频仍存在于 `audio/` 目录，但新增或修改的台词暂无音频，播放到该句时会自动跳过（短暂停顿后继续）。如需为新台词生成音频，请联系技术负责人。

## 文件结构

- `index.html`         — 排练工具主页面
- `script.md`          — 剧本文件（Markdown 格式，按幕拆分）
- `audio_index.json`   — 音频索引文件（记录每句台词对应的音频文件路径）
- `audio/`             — 预录 WAV 音频文件目录
- `README.md`          — 本说明文件

## 技术说明

- 纯前端实现（HTML/CSS/JS），无后端依赖。
- 剧本通过 `fetch('script.md')` 动态加载，音频映射通过 `fetch('audio_index.json')` 加载。
- 音频播放使用浏览器原生 `<Audio>` API 播放预录 WAV 文件，无需依赖 Web Speech API 或任何特定浏览器。
- 排练进度（当前幕、当前行、角色选择）保存在浏览器的 `localStorage` 中，不同设备独立存储。

## 常见问题

**问：修改 `script.md` 后，页面没有变化？**  
答：GitHub Pages 刷新需要几十秒到一分钟，请稍后强制刷新页面（Ctrl+F5）。

**问：某些台词没有声音，直接跳到下一句？**  
答：该台词暂无对应的预录音频，系统会自动跳过并继续。如需补录音频，请联系技术负责人。

**问：我可以自己在本地测试吗？**  
答：可以。将整个仓库克隆到本地，通过 `npx serve` 或 VS Code Live Server 启动，用浏览器打开 `index.html` 即可（直接用浏览器打开文件会因安全策略限制 `fetch` 而无法加载剧本和音频）。

**问：排练进度如何重置？**  
答：点击控制栏中的「⟳ 重置」按钮，或清除浏览器 localStorage 数据即可重置到第一句。
